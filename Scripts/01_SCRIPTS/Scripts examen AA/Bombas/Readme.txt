Esta carpeta contiene una función de Octave/Matlab "colebrook.m" para estimar el factor de fricción de Darcy f de acuerdo a la formulación de Colebrook (1939). Esta función puede bajarse de 
https://www.mathworks.com/matlabcentral/fileexchange/21990-colebrook-m

La expresión de Colebrook (1939) para f es implícita por lo que la función colebrook.m es iterativa. El artículo de Zigrang y Sylvester (1982), que se adjunta, presenta una de las aproximaciones explícitas más exactas.
